Global variables {{ variables|length }}

A variable remembers something about the reader while the story runs: points they collect, or which path they took. Every button can change one (set it to a value or add to it), a validation point can send readers on according to them, and any element text can show one by writing its name in curly braces, e.g. Score: {score}. Every change is written to the log.

The initial value decides the type once and for all: 0, 2.5 or -1 make a number (buttons can add to it); anything else, or a value in quotes like "start", makes text. Updates and rules that do not match the type are refused, so the story never crashes on a mismatch.
