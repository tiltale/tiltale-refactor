TilTale help

How TilTale fits together

TilTale is a local Django authoring tool. You edit a project here, then Regenerate to create a separate framework-free story website in /dist/.

Project files

Your active work lives in /project/. It contains the project database, content.xlsx, materials, colors and study logs.

Keep local data local. /project/ and generated /dist/ are ignored by Git and should not be committed.

Content and languages

The workbook uses this simple order:

content_id | note | en-US | nl-NL | ...

content_id is managed by TilTale. note is for your own context. Every named column after that is a language, so adding a language means typing its code in the next empty column.

If Excel is open: close content.xlsx before reloading or regenerating when TilTale reports that the workbook cannot be read or updated.

Main pages

Develop previews frames and the generated story. Flowchart shows frame connections. Project settings contains project-wide defaults. Results reads local or imported JSONL session logs.

First-start rule

No /project/ folder means there is no active project. Create one from TilTale or copy in a complete existing project folder. Do not run python manage.py migrate as a first-start setup step.
