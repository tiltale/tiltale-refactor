How TilTale fits together

You build the story here. Regenerate turns it into a plain website in /project/dist/ (HTML, CSS, JavaScript and one small log.php), which you upload to any web host with PHP.

The workflow

  1. Frames are the story's screens. Create them with + Frame; each gets a background and elements (speech bubbles, buttons, images…).
  2. Text comes from /project/content.xlsx: one row per text, one column per language. Pick a row for an element, or add one from the element's settings.
  3. Connections: set what a button does (go to a frame, end the story, or open a language). The Flowchart shows the result.
  4. Regenerate, then check the preview on different phones and run the Play-test.
  5. Upload /project/dist/; later download dist/logs/ from the server and import it under Results.

Participants and logs

Every page load writes a new log file <participant>--<visit>.jsonl. The participant ID comes from the URL (default parameter ppn, e.g. index.html?ppn=R_abc123 from Qualtrics) or is generated. Readers who reload continue where they were; incognito windows start over.

More languages

With two or more languages, each language gets its own folder in /dist/. Optional language-picker frames (+ Picker frame) form the start page /dist/index.html; their text is typed directly because no language has been chosen yet.

Keep data local

/project/ (including the generated website in /project/dist/) is ignored by Git. The full developer guide, with a table of every file, is in README.md.
