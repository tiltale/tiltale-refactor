Where things live

/project/ holds everything you make (database, content.xlsx, images, logs) — back it up. /project/dist/ is the generated website that you upload to your web host; it is rebuilt by Regenerate. Git ignores the whole project folder, so study data never ends up on GitHub. The buttons open the folders on this computer, for backing up, uploading, or just looking around.
